# tpf-tools

Códigos de ejemplo base para alumnxs de la materia **Taller de Producción Final** de la Licenciatura de Diseño Multimedial — Universidad Nacional de La Plata.

## Contenidos

### [p5js/](./p5js/)

Ejemplos con [p5.js](https://p5js.org/), biblioteca JavaScript para programación creativa.

| Carpeta | Descripción |
|---|---|
| [p5js/01-basico/](./p5js/01-basico/) | Figuras, colores y texto |
| [p5js/02-interactivo/](./p5js/02-interactivo/) | Mouse y teclado |
| [p5js/03-animacion/](./p5js/03-animacion/) | Movimiento con `frameCount` y trigonometría |

### [web/](./web/)

Template base de página web con HTML, CSS y JavaScript.

| Carpeta | Descripción |
|---|---|
| [web/template/](./web/template/) | Estructura mínima lista para usar |

## Cómo usar los ejemplos

1. Descargá o cloná este repositorio.
2. Abrí el archivo `index.html` de cualquier ejemplo directamente en el navegador (no necesita servidor).
3. Editá el código, recargá el navegador y observá los cambios.
